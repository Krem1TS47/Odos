# Odos v1 (Legacy)

This directory contains the original Python/Playwright implementation of Odos (JobAssist).

## Status
- **Archived & Unmaintained**: Superseded by Odos v2 (Manifest V3 local-first browser extension).
- Retained for reference and as a testbed for end-to-end fixture extraction.

## Running Tests
To run the v1 test suite using the virtual environment:
```powershell
.\.venv\Scripts\pytest legacy/tests
```

## Running the v1 CLI
```powershell
python -m jobassist --help
```
